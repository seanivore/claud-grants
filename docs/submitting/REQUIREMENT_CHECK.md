## Writing Style Guide
================================================================================

### Core Principles
1. Every technical detail must connect to grant focus areas:
   - Public good & decentralization
   - Developer education
   - Community building
   - DAO infrastructure
   - Cause-driven development

2. Transform specifications into value statements:
   - Don't just list a feature
   - Show how it advances their mission
   - Demonstrate understanding of their goals
   - Connect capabilities to community benefit

3. Never reduce complexity to brief bullets:
   - Expand each point to show full value
   - Include technical specifics (numbers, metrics)
   - Show both capability and purpose
   - Maintain persuasive narrative

### Writing Style Examples

❌ Before (Too Brief):
```markdown
Performance Metrics:
- 60fps animation
- Mobile optimization
- Memory efficiency
```

✅ After (Value-Focused):
```markdown
Educational Platform Performance Engineering:
- 60fps animation ensures fluid knowledge visualization, critical for maintaining learning momentum
- Mobile-first architecture democratizes access, reaching developers regardless of economic barriers
- Memory optimization (< 100MB) maximizes device compatibility, enabling global educational reach
- Cross-device synchronization maintains continuous learning pathways across all platforms
```

## Writing Quality Guidelines
================================================================================

### Document Review Questions
1. Does each section directly support grant goals?
2. Are technical specifications tied to value delivery?
3. Is the language persuasive and detailed?
4. Are metrics and capabilities clearly stated?
5. Does it demonstrate understanding of their mission?

### Value Connection Examples
When writing about:
- Performance: Show how it enables learning
- Architecture: Demonstrate community scaling
- Security: Highlight democratic access
- Documentation: Emphasize knowledge sharing
- Infrastructure: Focus on public good aspects
