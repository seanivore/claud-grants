## Primary Approach: o3-mini + Rive
1. **Generate Base Animation**
   ```js
   // o3-mini prompt
   "Generate JavaScript for bouncing ASCII $CLAUD text with physics,
    breaking into individual characters on collision"
   ```

2. **Convert to Rive**
   - Import generated JS animation
   - Set canvas: 100vw x 100vh
   - Export as `.riv`

3. **Implement**
   ```html
   <div id="animation" style="width: 100vw; height: 100vh;"></div>
   <script src="https://unpkg.com/@rive-app/web@latest"></script>
   <script>
     new Rive({
       src: 'animation.riv',
       canvas: document.getElementById('animation'),
       autoplay: true
     });
   </script>
   ```
