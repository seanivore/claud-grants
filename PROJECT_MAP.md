# Claud-Grants Project Map

## Directory Structure
```text
claud-grants/
├── CLAUDEME.md           # AI collaboration notes
├── README.md            # Project overview
├── SPECIFICATIONS.md    # Technical specifications
├── PROJECT_MAP.md      # Project structure
├── docs/
│   ├── analysis/        # Grant program analysis
│   │   └── GRANT-PROGRAMS-ANALYSIS.md
│   └── planning/        # Project planning
│       ├── BUILD_GUIDE.md
│       └── feature-timeline.md
├── grants/
│   ├── examples/        # Example applications
│   ├── templates/       # Grant templates
│   └── get-it-done/    # Active grant work
└── tasks/
```

## Component Relationships
- docs/analysis informs grant application strategy
- docs/planning guides implementation timeline
- grants/templates standardizes application process
- tasks/get-it-done tracks current progress
